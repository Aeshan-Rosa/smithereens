# Folio identity

The owner selected concept A, **Folio**: an ivory folded-paper S on forest green.

- Master artwork: `app/branding/smithereens-icon.png` (transparent PNG)
- Mac icon family: `app/mac/Contents/Resources/Smithereens.icns`
- In-app mark: `chrome/skin/default/zotero/smithereens-icon.png`
- Build script: `scripts/build-branding.sh`

The master artwork was generated with the built-in image generation tool. The app icon family is mechanically resized from that approved artwork using macOS `sips` and `iconutil`. Preview alternatives are retained in `concepts/`.

## Approved generation prompt

Use case: logo-brand. Create a premium minimal macOS app icon concept for Smithereens, a scholarly research library with an AI paper-reading assistant. Direction A, Folio: an original elegant ivory folded-paper ribbon that forms a subtle S, also suggestive of two open pages, on a deep forest-green rounded square tile. Strong simple silhouette, generous internal negative space, optical balance, readable at 32px. The tile has very subtle tactile depth, beautifully restrained studio lighting and a tiny soft edge highlight, not shiny plastic. Modern calm academic productivity software, polished and distinctive. One centered icon only, front view, fills 80 percent of a square image. Outside the rounded tile is fully transparent. No letters, words, captions, watermark, Zotero Z, sparkles, robot, brain, extra objects or mockup device. This is a logo exploration, not a screenshot.
